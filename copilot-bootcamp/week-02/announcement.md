## Facilitator notes on these posts

Lead with the 4:10 Thursday framing. Everyone in a contact center has had that moment and it does more recruiting than any description of analysis skills.

Do not promise that Copilot will do the analysis for them. Promise that it will cut the time between getting the report and having something to say. That is the true claim and it is still attractive.

If Week 1 attendance was soft, name it directly in the post rather than pretending it was fine: "Small group last week, which made the debrief better. Same format Tuesday." That reads as confident rather than defensive.
