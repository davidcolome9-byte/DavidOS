# MANIFEST

Complete file list for the Microsoft 365 Copilot Boot Camp package. 41 files.

Every scenario in every file uses fabricated data for a fictional institution called Riverstone Credit Union. No real member information, account data, or internal material appears anywhere in this package.

## Structure

```
copilot-bootcamp/
  week-01/ through week-06/   six files each
  shared/                     five files
```

## Week 01: Copilot as Researcher

| File | Description |
|---|---|
| facilitator-guide.md | 60 minute run of show, talking points, anticipated questions |
| participant-onepager.md | Printable: what they learn, practice, and submit |
| exercise.md | Four conflicting policy documents, build a call ready briefing |
| solutions-key.md | Worked strong response plus two failure modes |
| knowledge-check.md | Five questions with a reasoned answer key |
| announcement.md | Teams post, reminder, and email to drive attendance |

- **facilitator-guide.md** covers the ask, shape, verify pattern, a three pass demo that starts deliberately weak, and how to answer "is it reading my email right now."
- **participant-onepager.md** gives the prompt scaffold including the "say not stated instead of guessing" line.
- **exercise.md** contains a synthetic source pack of four documents that conflict in three places, one of which is out of date.
- **solutions-key.md** documents all three conflicts, the four gaps, and the two failure modes: the confident merge and verification that was not verification.
- **knowledge-check.md** tests source citation, permission scope, why summarizing drops exceptions, and the "not stated" instruction.
- **announcement.md** includes facilitator notes on why the two hour reminder outperforms the 48 hour post.

## Shared

- **prompt-library.md** contains 50 prompts organized into contact center operations (10), fraud review and disputes (10), quality assurance and coaching (8), reporting and analysis (9), internal communications (8), and prompt repair and agent building (5). Each has a fill in structure and most include an explicit instruction for handling missing information.
- **facilitation-faq.md** covers four types of skeptic and the different response each needs, a straight answer to "AI will replace us" that avoids the four phrases people distrust, a four cause diagnosis for low adoption, questions you must answer accurately, and what to do if the program is not working.
- **evidence-tracker.md** maps each week to an outcome type, measure, and artifact, provides a quality evidence log format, and drafts six promotion packet lines including one that reports what did not stick.

## Assumptions made and labeled inline

Marked as [ASSUMPTION] where they appear:

- Cohort size of 12 to 16, with alternate formats given for larger groups
- Submissions collected as replies in a Teams channel thread
- Mixed availability of Copilot in Excel across the cohort, with both paths supported
- Mixed agent creation permissions, with a full simulation path provided
- Teams supports preassigned breakout rooms for Week 3
- Facilitator can find ten minutes with most participants before Week 6
- No organization specific member communication template was supplied for Week 4
- Facilitator has confirmed the true answer to "is usage being tracked" before Week 1
